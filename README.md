# Personal Expense & Credit Risk Analytics Dashboard (Power BI)

## 📌 Overview
An end-to-end single-page executive Power BI analytics report designed to evaluate personal spending behaviors, card tier distributions, and credit risk exposure.

##  Key Technical Features
- **Executive KPIs**: Real-time aggregation of Total Monthly Spend, Avg Credit Score, Avg Credit Utilization, and Total Outstanding Balance.
- **Card Tier & Spend Breakdown**: Visual segmentation of spending habits across card tiers (Platinum, Gold, Signature, Silver, Basic) and expense categories.
- **Credit Profile Matrix**: Detailed tabular breakdown measuring payment ratios, utilization rates, and credit scores across distinct occupation segments.
- **Income vs. Credit Risk Analysis**: Dual-axis visual paired with an interactive slider for continuous data filtering.
- **Interactive Modeling**: Built-in dynamic cross-filtering across all visuals for seamless data exploration.

## Tech Stack
- **Tool**: Power BI Desktop
- **Data Transformation**: Power Query
- **Metrics & Calculations**: DAX (Data Analysis Expressions)
- **Data Modeling**: Relational Schema
